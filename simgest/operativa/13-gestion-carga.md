## 13. Revisar la gestión de carga

> **Objetivo**
>
> Consultar la cabecera y las líneas de una carga para comprobar documentos, unidades, bultos y datos logísticos visibles antes de continuar con la entrega.

## Cuándo utilizar este procedimiento

Utilízalo durante la preparación o revisión de una expedición cuando sea necesario comprobar qué documentos o líneas forman parte de la carga.

## Requisitos previos

- Carga o documento identificado.
- Cliente o referencia conocida.
- Información física de bultos, peso o palés cuando esté disponible.
- Líneas de entrega que deben incluirse.

## Vista general

Abrir carga
→ identificar cabecera
→ revisar documentos
→ revisar líneas
→ comparar bultos y cantidades
→ detener el proceso si faltan datos

## Procedimiento

### Paso 1. Abrir la carga correcta

Accede a **Gestión de Carga** y localiza la carga por cliente, documento, referencia o criterio disponible.

[![Pantalla de gestión de carga con datos de cabecera, documentos y líneas señalados](/assets/simgest/operativa/cap_24_gestion_carga.png =70%x)](/assets/simgest/operativa/cap_24_gestion_carga.png)

*Vista utilizada para comprobar los elementos asociados a una carga. Pulsa la imagen para abrirla a tamaño completo.*

### Paso 2. Revisar la cabecera

Comprueba los datos visibles relacionados con:

- cliente;
- documento o referencia;
- fecha;
- importes cuando aparezcan;
- unidades, bultos, peso o palés cuando estén informados.

### Paso 3. Revisar los documentos asociados

Confirma que los documentos que aparecen pertenecen a la carga seleccionada. No des por correcta una carga únicamente por el nombre del cliente.

### Paso 4. Revisar las líneas

Comprueba artículos, cantidades y cualquier dato logístico visible en la tabla inferior.

Compara con la preparación física cuando exista información de almacén.

### Paso 5. Detener el avance si faltan datos

No continúes cuando falten líneas, bultos o cantidades por verificar.

**Acción exacta para cerrar, confirmar o expedir una carga:** Pendiente de validación por Hacchi

## Resultado esperado

La carga consultada contiene los documentos y líneas esperados y no presenta diferencias conocidas entre la información de SIMGEST y la preparación física.

## Comprobación final

- [ ] Carga correcta.
- [ ] Cliente y referencia comprobados.
- [ ] Documentos asociados revisados.
- [ ] Líneas y cantidades comprobadas.
- [ ] Bultos, peso o palés comparados cuando existen.
- [ ] No se ha ejecutado una confirmación no documentada.

## Errores habituales

| Error | Riesgo | Actuación |
|---|---|---|
| Revisar solo la cabecera | Omitir líneas faltantes | Comprobar la tabla inferior. |
| Confundir cargas del mismo cliente | Preparar otra entrega | Comparar documento y referencia. |
| Cerrar con datos incompletos | Entrega incorrecta | Pendiente de validación por Hacchi |
