## Objetivo

Identificar correctamente al cliente y establecer las condiciones comerciales que se aplicarán al presupuesto.

## Antes de empezar

Confirmar el cliente, la referencia del trabajo, la dirección del proyecto y las condiciones pactadas.

## Procedimiento

### Datos del cliente

1. Seleccionar el **cliente** correcto.
2. Escribir o revisar la **referencia** del trabajo.
3. Comprobar la **dirección** y la **localidad**.
4. Revisar el **agente**.
5. Revisar el **transportista**, cuando corresponda.

### Condiciones comerciales

1. Revisar el **ejercicio**.
2. Revisar la **moneda**.
3. Confirmar el **almacén**.
4. Comprobar las **fechas** del documento.
5. Seleccionar la **forma de pago** correcta.
6. Revisar los **descuentos generales**.

## Control obligatorio

| Dato | Comprobación |
|---|---|
| Cliente | El código y el nombre corresponden al cliente real. |
| Referencia | Permite identificar el trabajo o proyecto sin ambigüedad. |
| Dirección y localidad | Coinciden con el centro o proyecto correcto. |
| Fechas | Son coherentes con la solicitud y la emisión. |
| Forma de pago | Coincide con las condiciones pactadas. |
| Descuentos | Están autorizados y no duplican descuentos aplicados en líneas. |

## Resultado esperado

La cabecera identifica correctamente el presupuesto y sus condiciones comerciales.

## Advertencias

> No continuar si el cliente o la dirección no corresponden al proyecto correcto.
