## 2. Crear una oferta o presupuesto

> **Objetivo**
>
> Crear en SIMGEST una Oferta/Proforma de Cliente con la cabecera, las notas y las líneas necesarias para presupuestar un trabajo.

## Cuándo utilizar este procedimiento

Utilízalo cuando deba prepararse una nueva propuesta para un cliente. La oferta debe estar completa y revisada antes de generar el PDF o convertirla en pedido.

## Requisitos previos

- Cliente identificado.
- Referencia o descripción del trabajo.
- Proyecto al que se asociará la oferta.
- Tarifa y forma de pago aplicables.
- Artículos, cantidades, medidas o descripciones necesarias.
- Fechas confirmadas cuando el proceso las requiera.

## Vista general

Abrir Ofertas
→ crear registro
→ completar cabecera
→ revisar notas
→ añadir líneas
→ guardar
→ comprobar la oferta

## Paso 1. Abrir la pantalla de ofertas

La documentación de origen sitúa el acceso en el módulo de proyecto u ofertas y la captura muestra el acceso **Ofertas** en la barra principal.

1. Abre el acceso **Ofertas**.
2. Entra en la pantalla **Oferta/Proforma de Cliente**.
3. Selecciona la acción de crear un registro nuevo.

**Nombre exacto del icono o atajo de alta:** Pendiente de validación por Hacchi

[![Pantalla de SIMGEST con el acceso a ofertas y la ventana Oferta/Proforma señalados](/assets/simgest/operativa/cap_s2_abrir_oferta.png =70%x)](/assets/simgest/operativa/cap_s2_abrir_oferta.png)

*Acceso visual a la pantalla desde la que se crean y consultan ofertas. Pulsa la imagen para abrirla a tamaño completo.*

**Resultado esperado:** la ventana está preparada para introducir una oferta nueva y no muestra datos de otra oferta que puedan confundirse con el nuevo registro.

## Paso 2. Completar la cabecera

La cabecera identifica el documento y condiciona el contenido posterior.

1. Selecciona el **Cliente** correcto.
2. Introduce una **Referencia** clara del trabajo.
3. Revisa la **Dirección** y la **Localidad** asociadas.
4. Selecciona la **Tarifa** indicada.
5. Comprueba las fechas visibles, incluidas fecha, solicitud o envío cuando proceda.
6. Asigna el **Proyecto** correspondiente.
7. Revisa margen, transporte u otros porcentajes visibles sin modificarlos si no existe una instrucción confirmada.
8. Comprueba la **Forma de pago** antes de añadir las líneas.

[![Detalle de la cabecera de una oferta con cliente, referencia, tarifa, fechas y proyecto](/assets/simgest/operativa/cap_s2_cabecera_detalle.png =70%x)](/assets/simgest/operativa/cap_s2_cabecera_detalle.png)

*Campos de cabecera que deben comprobarse antes de trabajar con las líneas. Pulsa la imagen para abrirla a tamaño completo.*

### Qué debe comprobar

| Campo | Control |
|---|---|
| Cliente | Código y nombre corresponden al destinatario |
| Referencia | Permite identificar el trabajo sin ambigüedad |
| Dirección y localidad | Corresponden al centro o dirección aplicable |
| Tarifa | Es la indicada para la operación |
| Proyecto | Coincide con el proyecto real |
| Fechas | Están confirmadas o quedan pendientes de validación |
| Forma de pago | Coincide con la condición acordada |

## Paso 3. Revisar las notas

El panel derecho contiene notas u observaciones relacionadas con el cliente o la oferta.

1. Lee las notas existentes antes de añadir información.
2. Conserva las observaciones que sigan siendo aplicables.
3. Añade únicamente información necesaria para interpretar la oferta.
4. No borres notas de origen sin una instrucción confirmada.
5. Evita introducir información personal innecesaria.

**Diferencia funcional entre notas del cliente, notas internas y mensaje de oferta:** Pendiente de validación por Hacchi

[![Oferta con el panel de notas y la tabla de líneas señalados](/assets/simgest/operativa/cap_s2_notas_lineas.png =70%x)](/assets/simgest/operativa/cap_s2_notas_lineas.png)

*Relación entre las observaciones de la oferta y el detalle inferior de artículos. Pulsa la imagen para abrirla a tamaño completo.*

## Paso 4. Añadir o revisar las líneas

Cada línea debe representar un artículo o concepto real del presupuesto.

1. Añade el artículo correcto.
2. Revisa la descripción visible.
3. Introduce o comprueba las unidades.
4. Comprueba el precio.
5. Revisa descuentos e IVA.
6. Verifica cualquier columna de comisión, transporte, acabado o aclaración que esté activa.
7. Repite el control antes de pasar a la siguiente línea.

[![Oferta completa con cabecera, panel de notas y líneas del presupuesto señaladas](/assets/simgest/operativa/cap_01_oferta_proforma.png =70%x)](/assets/simgest/operativa/cap_01_oferta_proforma.png)

*Vista conjunta utilizada para comprobar que cabecera y detalle pertenecen a la misma oferta. Pulsa la imagen para abrirla a tamaño completo.*

### Criterio para artículos configurables

Cuando una línea dependa de medidas, variantes, tela, acabado o escandallo, revisa también:

- [Partes tapizables y variantes](/simgest/operativa/06-articulos-variantes-escandallos)
- [Ficha de artículo y escandallo](/simgest/operativa/07-ficha-articulo-escandallo)

## Paso 5. Guardar y volver a comprobar

Guarda la oferta cuando cabecera, notas y líneas estén completas. Después, vuelve a revisar el registro guardado para confirmar que los datos permanecen en la oferta correcta.

**Acción final que convierte la oferta aprobada en pedido:** se documenta en la fuente como **Confirmar**, pero el criterio de autorización y el momento exacto se mantienen como **Pendiente de validación por Hacchi**.

## Resultado esperado

La Oferta/Proforma queda guardada con cliente, referencia, proyecto, condiciones y líneas coherentes, preparada para la revisión previa a su emisión.

## Comprobación final

- [ ] Cliente correcto.
- [ ] Referencia clara.
- [ ] Proyecto asignado.
- [ ] Tarifa y forma de pago revisadas.
- [ ] Fechas confirmadas o señaladas.
- [ ] Notas leídas y actualizadas sin borrar información necesaria.
- [ ] Artículos, cantidades, precios, descuentos e IVA revisados.
- [ ] Oferta guardada y reabierta para comprobar el resultado.

## Errores habituales

| Error | Cómo detectarlo | Actuación |
|---|---|---|
| Añadir líneas antes de completar la cabecera | Falta cliente, proyecto o tarifa | Completar la cabecera antes de continuar. |
| Utilizar una referencia genérica | No permite localizar el trabajo | Sustituirla por una descripción identificable. |
| Heredar notas de otro contexto | Las observaciones no corresponden a la oferta | Revisar el origen antes de guardar. |
| Modificar porcentajes sin criterio | Cambian importes o condiciones | Pendiente de validación por Hacchi |
