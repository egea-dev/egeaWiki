## Objetivo

Confirmar que el presupuesto, el PDF y las necesidades de compra han sido revisados antes de finalizar.

## Lista de comprobación

- [ ] Cliente correcto.
- [ ] Dirección correcta.
- [ ] Referencia revisada.
- [ ] Fechas revisadas.
- [ ] Forma de pago correcta.
- [ ] Todas las líneas incluidas.
- [ ] Cantidades comprobadas.
- [ ] Precios comprobados.
- [ ] Descuentos revisados.
- [ ] IVA revisado.
- [ ] Oferta guardada.
- [ ] PDF revisado.
- [ ] Materia prima recalculada cuando corresponde.
- [ ] Previsión de compra comprobada.

## Resultado esperado

El procedimiento queda terminado sin datos pendientes de revisión y con trazabilidad entre la oferta, el PDF y la previsión de compra.
